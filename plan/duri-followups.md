# Application follow-ups — public summary

The original private-app-specific operational plan has been retained verbatim in
a private archive. Its proposals and old completion claims are not new task
assignments or deployment authorization.

The public homelab contract is artifact-based: build from a locally supplied
source checkout, push a versioned image, pin it in Compose, reconcile deliberately,
and verify the version actually served. `DURI_DIR` supplies the source path;
there is no public private-repository-name default.

App-side feature/onboarding work stays with the app's private records. The public
service specification and runbooks remain the source for the hosting interface.
